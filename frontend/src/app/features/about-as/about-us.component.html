About the Project

CryptoTrade is a full-stack trading platform clone built on top of the Binance Spot Testnet. The project was designed and developed entirely by one developer as part of the RS School JavaScript/Frontend Developer course.

Artyom Migalev

Full-stack Developer

Frontend Developer with experience in Angular and React ecosystems. Built this project as a full-stack application — Angular 21 frontend with Signals and a NestJS backend with JWT authentication and HMAC-SHA256 signing for secure Binance API integration.
