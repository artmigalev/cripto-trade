## 🚀 Live Demo
[CryptoTrade App](https://cripto-trade-e35v.vercel.app)

## 📋 Description
Cryptocurrency analysis and trading platform built with Angular 21 and Binance Testnet API.

## 🛠 Tech Stack
- Angular 21 (Standalone, Signals, OnPush)
- Angular Material + Tailwind CSS
- Binance Testnet API (REST + WebSocket)
- NestJS (backend — in progress)
